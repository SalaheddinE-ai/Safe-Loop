# Observability guide
- **Metrics** (`/metrics`): see `src/safeloop/observability/metrics.py`. Labels are bounded: provider, model, kind, outcome,
  failure_category, status, reason, kind(sandbox failure). Cost metrics exist only where a cost is reported (`source=reported`)
  or computed from configured pricing (`source=estimated`); local models report none.
- **Dashboards**: generated by `scripts/gen_dashboards.py` into `monitoring/grafana/dashboards` (A overview, B workflow,
  C economics, D sandbox, E guardrails) and provisioned read-only. "Attempts per task" is approximated by model calls per task.
- **Alerts** (`monitoring/prometheus/alerts.yml`): provider failure ratio, sandbox failure ratio, queue depth, p95 latency,
  scrape target down. Thresholds are untuned starting points; **no alert has been fired in a test**. Validate syntax with
  `make check-monitoring` (promtool in Docker).
- **Logs**: JSON to stdout (`timestamp, severity, service, event, task, attempt, duration, outcome, reason`); keys matching
  key/token/secret/password/authorization and bearer/`sk-` values are redacted; prompts and code are never logged. Promtail
  ships Compose container logs to Loki; query `{service="api"} | json` in Grafana.
- **Tracing**: optional OpenTelemetry (`[otel]` extra). Spans exist for `safeloop.task`, `safeloop.model_call` and `safeloop.sandbox_collect`, only when those stages run. Enabled by `SAFELOOP_OTLP_ENDPOINT`; tested with an in-memory exporter only (no Tempo/collector).
- A static test checks that every metric referenced by dashboards/alerts is actually exported. It does not prove Grafana loads them.
